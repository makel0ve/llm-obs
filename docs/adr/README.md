# Architecture Decision Records

This directory records architecture decisions that affect operator guarantees,
security boundaries or future migration work.

Use this format for new ADRs:

- Title: `ADR NNNN - Short Decision Name`
- Date
- Status
- Context
- Decision
- Consequences
- Current compatibility or open decisions when relevant
